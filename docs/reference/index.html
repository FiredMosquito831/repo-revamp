Agents

3 subagents. One builds, one investigates, one verifies.

  • repo-investigatorRead-only investigation for a repository revamp — recon, feature and configuration inventory, hosting and subdomain options, risks, and a numbered spec with a recommendation per question. Use before any build, when the scope or the facts are not yet established.agents\repo-investigator.md
  • revamp-verifierIndependently verify a completed revamp — the product boundary, the deterministic build, the live URLs, the served commit, the claims ledger and the legal texts — and report CONFIRMED, UNVERIFIED and NOT DONE. Use after an implementer reports shipped, before the orchestrator relays anything.agents\revamp-verifier.md
  • site-builderBuild the public site for a repository revamp in its own worktree — the generated docs/ site, the deterministic builder, the reviewed screenshot set, the design system, SEO and the README — then commit, push and open a draft PR. Use when a revamp spec is approved and one implementer must build the site. Never merges or deploys.agents\site-builder.md
