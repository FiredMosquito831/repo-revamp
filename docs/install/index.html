Requirements

What the plugin needs, and what each piece is for
RequirementWhy
Claude Code with plugin supportLoads the skill, the commands and the agents.
gitThe revamp works in a worktree and commits to a branch.
gh, authenticatedThe GitHub steps: pull requests, Pages, repository metadata.
Python 3.12Runs the builder and the three plugin scripts.
Pillow and imagehash, in a scratch environmentOnly for perceptual clustering and contact sheets. The inventory and SHA-256 de-duplication use the standard library.

Nothing else is required. The builder needs Jinja2 and MarkupSafe, pinned in the site's own requirements file; the plugin's install does not add them to any product manifest.

What "installed" means

After a restart the plugin contributes four things to a session: the repo-revamp skill, which is model-invocable, so saying "revamp this repo" loads it; five slash commands under the repo-revamp prefix; three subagents that the skill can delegate to; and the working files the playbook writes outside the repository. It adds no hooks, no MCP servers and no LSP servers.

The skill is the contract and the state machine. The commands are entry points into it. The agents are the delegated workers. Nothing runs until you ask for a revamp, and nothing in your repositories changes until a revamp command starts.

Update and uninstall

Updates come from the marketplace. Refresh the marketplace and reinstall the plugin; the version in .claude-plugin/plugin.json is the only place the version is declared.

To remove it, uninstall the plugin and, if you added it only for this, remove the marketplace:

The plugin does not touch your repositories

Installing it adds a skill, five commands and three agents to Claude Code. It does not clone, edit or configure any repository until you run a revamp command on one.
